## Pharmastore analysis project

An data analysis project using SQL language and Power BI for visualization. 

It analyses the sales of an online pharmacy store in period of 2021-2024
Some of the queries are reffering to: 
- What is the most selling product line?
- Which product line generated the highest revenue?
- Which drug(or drugs) had the most sales
- How many times a customer made an order and which category
- Which category had the most sales

I also created some triggers to update some table fields automatically instead of manually

There is also included a document with software specification and some diagrams.
